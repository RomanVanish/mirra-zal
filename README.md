Каждый мессенджер встречается 2 раза: в окне «Как вам удобнее связаться?» (внизу `index.html`, блок `<dialog class="sheet">`) и в разделе «Контакты». Если какого-то способа нет — удалить строку `<li>…</li>` в окне и кнопку в «Контактах».

Все кнопки «Забронировать дату», «Связаться» и плавающая кнопка открывают это окно; без JavaScript они ведут к разделу «Контакты».

**Заглушки и демо (сейчас включены, чтобы видеть задумку):**
- места под ещё не снятые видео показываются с пометкой «скоро» — это класс `show-placeholders` у `<body>`. Убрать класс — заглушки исчезнут, останутся только видео с файлами;
- пары «мягкий / яркий свет» с красной пометкой «демо» сделаны из имеющихся фото (`assets/img/light/_demo-…`). Когда будут настоящие снимки — заменить; искать в `index.html` по слову `ДЕМО`.

После замены убедиться, что поиск по `ЗАПОЛНИТЬ` и `ПРОВЕРИТЬ` в `index.html` ничего не находит.

## Фото

Каждое фото — два файла WebP, качество ≈ 80, ширина ровно 800 и ровно 1600 px:

```
assets/img/<папка>/<помещение>-<номер>-800.webp
assets/img/<папка>/<помещение>-<номер>-1600.webp
```

Например `assets/img/master-50/master-02-800.webp`. Сжать: [squoosh.app](https://squoosh.app) (WebP, Quality 80, Resize по ширине) или командой:

```
cwebp -q 80 -resize 800 0 исходник.jpg -o master-02-800.webp
cwebp -q 80 -resize 1600 0 исходник.jpg -o master-02-1600.webp
```

**Добавить фото в карточку помещения:** в `index.html` найти карточку (`id="room-master"` и т.п.), скопировать строку `<figure class="gallery__slide">…</figure>`, поменять имена файлов, `alt` и `height` у большой версии (1200 для 4:3, 900 для 16:9). Счётчик «1 / N» и стрелки появятся сами.

**Добавить фото в общую галерею:** скопировать строку `<button class="mosaic__item">…</button>` в разделе «Галерея».

**Заменить фото:** положить новый файл с тем же именем — код менять не нужно (если поменялись пропорции — поправить `height`).

Исходники JPG/PNG можно держать рядом — в репозиторий они не попадут (`.gitignore`).

Что ещё снять — в `doc/Необходимые фото и видео.md`.

## Новое помещение (например, большой зал 65 м²)

1. Папка `assets/img/hall-65/`, фото `hall-01-800.webp` и т.д.
2. В `index.html` скопировать целиком блок `<article class="room …">…</article>` зала «Лотос», поменять `id`, фото, название, площадь, тексты.
3. Удалить блок `<aside class="soon">…</aside>` («Скоро»).
4. В строке фактов поправить «10–50» и «4 помещения».

## Видео

Файлы MP4 класть в `assets/video/`, обложки (кадр из ролика, WebP 1600 px) — в `assets/img/common/`. Параметры сжатия — в `doc/T3.md`, п. 11.

Места под видео уже есть на странице и скрыты. Чтобы показать — вписать путь в `data-video` и обложку в `data-poster`. Видео открывается на весь экран поверх страницы.

| Видео | Где | Что найти в `index.html` |
|---|---|---|
| Обзор | Ссылка «Видео-обзор» на первом экране + карточка над общей галереей | `data-video-id="overview"` |
| Помещения | Плашка с превью под фото помещения | `video-thumb` внутри карточки (`id="room-lotos"` и т.д.); длительность — в `data-duration` (например `0:25`), иначе подставится сама |
| Санузлы | Плашка с превью под списком «Детали» | `data-title="Видео: санузлы"` |
| Как пройти | Под схемой в «Контактах», вертикальная карточка | `data-title="Как пройти"` |

Пример: `data-video="assets/video/lotos-35.mp4" data-poster="assets/img/common/lotos-poster.webp"`

## Свет: мягкий / яркий

**В карточке кабинета (сейчас).** Две фотографии с одной точки — при мягком и при ярком свете:

```
assets/img/light/zolotoy-soft-800.webp   assets/img/light/zolotoy-soft-1600.webp
assets/img/light/zolotoy-work-800.webp   assets/img/light/zolotoy-work-1600.webp
```

(для «Цапли» — `tsaplya-…`). В `index.html` в галерее кабинета уже есть закомментированный блок `gallery__slide--light` — убрать `<!--` и `-->` вокруг него. Пара станет первым слайдом, на фото появится переключатель «Мягкий свет / Яркий свет» с плавным переходом. Если пропорции не 4:3 — поправить `height` (900 для 16:9).

**Отдельный блок «Свет под формат» (на будущее).** Раздел `id="light"` скрыт, пока в нём нет пар. Внутри есть закомментированный пример `light__set` — скопировать над строкой `<div class="light__rooms" …>` и вписать файлы. Если помещений с парами несколько — появится переключатель помещений.

## Публикация (GitHub Pages)

Сайт опубликован: https://zal.mirra-spb.ru — репозиторий https://github.com/RomanVanish/mirra-zal (ветка `main`, корень).

**Как обновить сайт:** изменить файлы → `git add -A` → `git commit -m "что поменяли"` → `git push`. Через 1–2 минуты изменения на сайте. Если поменяли `style.css` или `main.js` — увеличить номер `?v=` в их подключении в `index.html`, иначе у посетителей может остаться старая версия из кэша.

- DNS (Beget): `zal` → CNAME `romanvanish.github.io` — уже настроено.
- HTTPS: сертификат Let's Encrypt выпускает и продлевает GitHub сам, «Enforce HTTPS» включён.
- Файл `.nojekyll` не удалять: без него GitHub не отдаёт файлы, имена которых начинаются с «_».
- Файл `CNAME` не удалять.
